v0.0.1 2026-08-19 21:29 26 项
  • misc# AperturePrism-AI-Review v0.0.1
  • misc独立开发的 GitHub Issue 分析与 Pull Request 审查平台首个版本。
  • misc## 功能
  • misc- **Issue 分析**：GitHub Webhook（验签 + 幂等入库）→ 多模型路由 → 结构化分级（S0-S3 / P0-P3 / 完整度）→ 幂等评论 + 自动打标
  • misc- **PR 审查**：diff 解析与行映射、大小/预算降级、结构化 finding + 服务端严重度策略、幂等 Review 发布
  • misc- **重复 Issue 检测**：标准化 + 信号抽取 + 全文/向量（pgvector）召回 → 模型裁决
  • misc- **仓库记忆**：反思沉淀 → 合并 Agent → 上下文回灌
  • misc- **Agent Skills / 专家团队**：6 个内置技能 + 多专家并行审查
  • misc- **仓库互助**：注册 GitHub 账户 → 定时给目标仓库点星
  • misc- **手动触发**：WebUI 按仓库 + 编号触发 Issue/PR（`POST /tasks/manual`）
  • misc- **广告识别**：分析前自识别广告/垃圾 Issue，按 `spam_handling` 策略关闭或删除（可配置）
  • misc- **Web 控制台**：深色玻璃 UI、GitHub OAuth 登录 + 管理员角色、SSE 实时事件、操作审计、配置备份、用户管理
  • misc- **QQ 机器人**：NTQQ 第三方协议（OneBot 11 / Satori / Milky）+ 官方开放平台 api-v2
  • misc- **AstrBot 插件**：`plugins/astrbot_plugin_apertureprism/`（napcat + QQ 官方桥接）
  • misc- **运维**：一键安装脚本、Docker 全栈打包、迁移/备份脚本、健康检查、CI 构建 GHCR 镜像
  • misc## 发布内容
  • misc- 源码包：`AperturePrism-AI-Review-v0.0.1-source.zip`（`git archive` 导出，不含密钥/环境文件）
  • misc- 镜像：GitHub Actions 构建并发布到 `ghcr.io/bb0813/apertureprism-ai-review/<target>:v0.0.1`（api / analysis-worker / index-worker / scheduler / qq-bot / migrate / web）
  • misc## 快速开始

  • miscdocker compose -f docker/docker-compose.prod.yml --env-file .env.production up -d
